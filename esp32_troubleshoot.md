## 🧪 Тестовые команды

### Поиск ESP32 в сети:
```bash
cd /home/egor/Desktop/project
python3 -c "
import socket
import time
for i in range(1, 255):
    ip = f'192.168.125.{i}'
    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sock.settimeout(0.1)
    try:
        sock.sendto(b'PING', (ip, 3333))
        print(f'Sent to {ip}')
        resp, addr = sock.recvfrom(1024)
        print(f'Response from {addr}: {resp}')
    except:
        pass
    sock.close()
"
```
